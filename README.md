# RapDiss

Аддон для WoW Forever: мобы иногда дисят игрока рэп-строчкой. Дис появляется в чате и пузырём над портретом моба, а видят его все, у кого стоит аддон.

Раньше аддон назывался Lumen Diss.

## Как работает

- Когда начинаешь бой с мобом в цели, он может выдать дис. Шанс 1-2%, зависит от расы и класса:
  - 1% всем;
  - +0,5%, если есть дисы под твою расу;
  - +0,5%, если есть дисы под твой класс.
- Режим «Повышенные дисы» удваивает этот шанс: 2-4%.
- Босс при первой встрече за последние 2 часа дисит с шансом 25%, и в режиме повышенных дисов тоже. Если снова встретить его раньше чем через 2 часа, шанс обычный.
- В одном бою может быть только один дис. Между дисами минимум 30 секунд, кроме первой встречи с боссом.
- Если в группе аддон стоит у нескольких игроков, один моб дисит только одного из них.
- Дисы под твою расу и класс выпадают чаще общих.
- Есть именные дисы: они выпадают только персонажу с определённым именем и фамилией. Пока такой дис ни разу не выпадал, он достаётся в 5% дисов этого персонажа, потом в 1%.
- Строка в чате: «Zin Torn дисит Зумби: ...». Над портретом цели появляется пузырь с текстом.
- Дисы уходят гильдии и группе.
  - По умолчанию ты видишь только дисы тех, кто рядом, до 100 м.
  - С галочкой «Массовое отображение» видны дисы всей гильдии, с названием зоны.

## Настройки

«Настройки → AddOns → RapDiss» или `/rap настройки`.

**Пузырь над портретом**

- **Пузырь с дисом.** По умолчанию включено.
- **Дизайн:** Подсказка, Тёмный, Рэп, Свиток или Только текст.
- **Размер:** от 50 до 200%.
- **Время на экране:** авто (дольше для длинных дисов) или от 1 до 15 секунд.
- **Высота над портретом.**
- **Пример пузыря:** кнопка «Показать» показывает пузырь с текущими настройками.

**Чат**

- **Строка с дисом в чате.** По умолчанию включено.

**Дисы**

- **Повышенные дисы:** обычный шанс ×2, у боссов прежний. По умолчанию выключено.
- **Показывать дисы согильдийцев.** По умолчанию включено.
- **Массовое отображение.** По умолчанию выключено: видны только дисы рядом.
- **Делиться своими дисами.** По умолчанию включено.

## Команды

| Команда | Что делает |
|---|---|
| `/rap` | сколько тебя задисили, кто чаще, последний дис, текущий шанс |
| `/rap настройки` | открыть настройки |
| `/rap x2` | включить или выключить повышенные дисы |
| `/rap бабл` | включить или выключить пузырь над портретом |
| `/rap стиль [название]` | сменить дизайн пузыря, без названия - следующий |
| `/rap размер 150` | размер пузыря в процентах |
| `/rap пример` | показать пузырь |
| `/rap чат` | включить или выключить строку в чате |
| `/rap масс` | дисы всей гильдии или только рядом |
| `/diss` | тест: шанс 100%, без паузы между дисами. Ещё раз выключает |

## Установка

Скачай архив из [Releases](https://github.com/lloqloki/rapdiss/releases) и распакуй папку `RapDiss` в `World of Warcraft\_forever_\Interface\AddOns`. Затем полностью перезапусти игру.

**Если стоял Lumen Diss:** при первом запуске RapDiss сам перенесёт статистику и настройки и выключит старый аддон. Потом сделай `/reload`, а папку `LumenDiss` можно удалить. С игроками, у которых ещё стоит Lumen Diss 1.1.0, RapDiss понимает друг друга.

## Свои дисы

Все дисы лежат в `Data.lua`. Можно дописать свои:

- `race` задаёт расы: `Orc`, `Troll`, `Tauren`, `Scourge` (нежить) и т.д.;
- `class` задаёт классы: `WARRIOR`, `MAGE` и т.д.;
- `who` делает дис именным: `{ "Имя Фамилия" }`, регистр не важен;
- `{name}` заменяется на ник игрока.

Тексты дисов: ШиЗик.
